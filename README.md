Fanuc India Packing App – Frontend
A modern Next.js web application for managing packing and sales order workflows, featuring role-based dashboards for Sales and Admin users.

---

## Features

- **Authentication:** Secure login with JWT tokens
- **Role-based Dashboards:** Distinct interfaces for Admin and Sales users
- **Admin Features:**
  - View and manage all sales orders
  - Edit order status and priority inline
  - Search/filter by product, date, or user
  - User and product lookup and management
  - Real-time data updates
- **Sales Features:**
  - View personal orders
  - Submit and track sales orders
  - Status and remarks management
  - Export and import via Excel
- **Modern UI:** Built with Tailwind CSS and shadcn/ui components
- **Responsive Design:** Optimized for desktop and mobile devices
- **Dark/Light Theme:** Automatic and manual theme switching

---

## Tech Stack

- **Framework:** Next.js 14+ with React 18+
- **Styling:** Tailwind CSS with shadcn/ui
- **UI Components:** shadcn/ui, Lucide React
- **HTTP Client:** Axios for API integration
- **Forms:** React Hook Form
- **Notifications:** Toast UI (shadcn or custom)
- **TypeScript:** Full type safety and interfaces
- **Icons:** Lucide React
